# 🎬 Movique – Movie Streaming & Watchlist Web App

Movique is a full-stack movie web application that allows users to explore movies, watch trailers, manage a personal watchlist, and interact with reviews and ratings after authentication. The project demonstrates a complete integration of frontend, backend, authentication, and database operations.

---

## 🚀 Features

- 🔐 User Authentication (Register / Login using JWT)
- 🎥 Browse and explore movie listings
- ▶️ Watch movie trailers / playback after login
- 📌 Add or remove movies from watchlist
- ⭐ Add ratings and reviews for movies
- 🧑‍💻 Personalized user dashboard
- 💾 Persistent data storage using database
- 🔄 RESTful API integration between frontend and backend
- 📱 Responsive and user-friendly UI
